# ~/.claude

A "thin harness, fat skills" configuration for [Claude Code](https://claude.com/claude-code): a lightweight
AI coding agent paired with a large library of structured skills, enforcement
hooks, and a self-learning memory layer (OpenWolf).

**[→ Read the full architecture explainer](https://paulchangmckay.github.io/brain/)**

The published site covers how skills, hooks, OpenWolf, and custom agents fit
together, plus a reference page for every skill in this repo.
