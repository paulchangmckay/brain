- Claude Code acts as a lightweight execution harness — deterministic shell tools, minimal MCP servers, basic filesystem commands.
- `CLAUDE.md` and project documentation are the "Fat Skills": read as structured data, executed against strictly.
- Context management, not model capability, is the bottleneck — every layer of this system exists to protect the token window.
