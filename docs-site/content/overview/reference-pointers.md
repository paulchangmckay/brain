Not every piece of infrastructure detail belongs in `CLAUDE.md` directly —
some of it is dense enough, or specific enough, that it deserves its own
dedicated reference instead of a paragraph squeezed in alongside everything
else. This page exists to point at where those live rather than to explain
them inline. Custom agent definitions, how plugins get registered locally,
the convention this repo follows for brand and document-output work, and how
external skills get integrated in — each of those has its own reference
elsewhere, reachable from the [Skills Reference](/skills) page.

The job of this page is routing, not depth: if you're looking for one of
those topics, the answer is "go there," not a summary here that risks
drifting out of sync with the real reference.

Source of truth: `CLAUDE.md` § 7 Reference Pointers.
