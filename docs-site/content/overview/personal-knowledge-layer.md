- The `brain` MCP server is a filesystem server rooted at `~/brain/` (`people/`, `companies/`, `concepts/`, `decisions/`) for cross-project, personal knowledge.
- Before answering questions about people, companies, or past decisions, the relevant `brain` subdirectory should be listed and read first; significant decisions get written back the same way.
- Three memory layers stay distinct rather than duplicating each other: `brain` (cross-project/personal), `.wolf/cerebrum.md` (project-specific patterns), and Claude Code's native auto-memory (facts about working with Claude Code itself, across all projects).
