# ~/.claude Reference

A local, personal-reference docs site for the "thin-harness, fat-skills" system in `~/.claude` — not published, no remote, browsed locally with `blume dev`.

- **[Harness Overview](/overview/core-philosophy)** — one page per `CLAUDE.md` numbered section (Core Philosophy, Process Layer, Infrastructure Layer, New Project Bootstrap, Personal Knowledge Layer, Knowledge Graph, Reference Pointers).
- **[OpenWolf Integration](/openwolf)** — the self-learning memory and enforcement layer.
- **[Skills Reference](/skills/brainstorming)** — one auto-generated page per skill in `skills/`, kept in sync with `npm run sync`.

Content here is authored three ways: auto-pulled from `SKILL.md` files (regenerate with `npm run sync`), hand-authored or Claude-drafted on instruction, and linked rather than duplicated where a source of truth already exists elsewhere in the repo. See `docs-site/README.md` for how to extend it.
