# Web Interface Guidelines

A correctness checklist for web UI, covering the areas outside pure
accessibility (ARIA, contrast, keyboard focus order — those already have a
full WCAG 2.2 AA reference at
`senior-engineering-partner/references/ui-design-and-accessibility.md`;
this file deliberately doesn't duplicate them).

See `references/checklist.md` for the full checklist, organized by area:
forms, animation, typography, content handling, images, navigation & state,
touch & interaction, dark mode & theming, internationalization, hydration
safety, and content/copy.

This is a correctness/polish pass, not an aesthetic-direction skill — it
runs alongside whichever taste-skill picked the visual direction, not
instead of one.
